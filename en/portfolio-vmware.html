About this Project

VMware Management Console Interface — a virtual machine management console designed for Ethan Group, an Australian telecom technology company specializing in virtual machine software development and maintenance, whose largest client is Melbourne Airport.

Scope of work included planning pages such as Dashboard, Form Management, Finance Management, Service Request, My Tickets, and My Documents — covering client requirements (User Story), the Design System, defining user permissions, mapping the User Flow, and extending the visual design into Mockups / Prototypes.

Responsive design allocation: Desktop (60%) / Tablet (30%) / Mobile (10%).

Design System

Dashboard

The Dashboard includes the following features:

Announcements: a quick shortcut on entering the page, showing only the 3 latest announcements.

Service Request: quickly order a service; once ordered, it opens a sub-page.

My Tickets: shows my 5 most recent tickets.

Finance Management: visible to management only, hidden from end users.

My Documents: shows documents administrators share with employees, with visibility varying by permission level.

Form Management

The form system included three roles, the end-user, the form administrator, and the form auditor. The three roles have different page layouts for different permission levels. This is a very large and complex project, with the different user habits at every level taken into consideration.

Finance

The financial system consists of three parts, spending trends, the spending variance, and the cost center budget allocation. It can create monthly and departmental financial reports, compile the budget allocation for each month, list the months with overspending observed, and make cost breakdown inquiries.
