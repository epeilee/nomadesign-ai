About this Project

This flu-testing app is designed for medical professionals running high-volume testing.

  1. Photograph the test strip using the phone's built-in camera
  2. Analyze the flu result in 3 seconds
  3. The result shows positive or negative for Influenza A and B, along with likely symptoms
  4. Save results and data to a database, supporting large-scale screening and record-keeping for professionals
