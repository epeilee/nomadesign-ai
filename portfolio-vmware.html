About this Project

虛擬機管理者介面設計 VMware Management Console Interface。客戶為澳洲電信科技商 Ethan Group，主要業務為虛擬機軟體開發維護，最大客戶為 Melbourne Airport。

工作別包含執行 Dashboard、Form Management、Finance Management、Service Request、My Tickets、My Documents等專案頁面規劃，包含客戶需求 User Story、Design System、定義使用者權限、規劃操作流程 User Flow，及視覺延展 Mockup / Prototype 設計。

RWD 規劃：各裝置比重為 Desktop(60%) / Tablet(30%) / Mobile(10%)。

Design System

Dashboard

Dashboard包含功能有：

公告：是進入頁面的快捷方式，只顯示3條新公告。

服務請求：可以快速訂購服務，訂購服務後會進入子頁面。

我的事件：將顯示我最近的5張票務。

財務管理：只在管理層顯示，終端用戶不顯示。

我的文件：會顯示管理員給員工查看的文檔，根據權限不同，會有不同的顯示。

Form Management

表單系統涉及三個角色，用戶、表單管理員和表單審核員。三個角色針對不同的權限有不同的頁面佈局。這是一個非常龐大和復雜的項目，需要考慮到各個層面用戶的不同習慣。

The form system included three roles, the end-user, the form administrator, and the form auditor. The three roles have different page layouts for different permission levels. This is a very large and complex project, with the different user habits at every level taken into consideration.

Finance

財務系統包含三部分，一個是消費趨勢，一個是消費差異，最後是各部門花費。可以完整的呈現每個月、每個部門的財報，甚至可以輸入每個月的預算分配，並且列出超支的月份，可以提出費用明細查詢。

The financial system consists of three parts, spending trends, the spending variance, and the cost center budget allocation. It can create monthly and departmental financial reports, compile the budget allocation for each month, list the months with overspending observed, and make cost breakdown inquiries.
